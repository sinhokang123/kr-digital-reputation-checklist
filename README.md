## 1. 원문 삭제부터 검색 잔존 정리까지 4단계 체크리스트

1. **표면 전수 탐색 (원문·미러·검색 캐시 분리)**
   - 원문 URL 1건만 확인하지 말고, 외부 펌글·아카이브·스크랩 복사본과 구글·네이버 검색 스니펫 및 이미지 썸네일 URL을 별도 목록으로 분리 채증합니다.
2. **증거 보존 및 권리 근거 정리**
   - 삭제 신청 전에 PC 원본 URL, 작성 시각, 본문·댓글 캡처, 개인정보 노출·허위사실·저작권 침해 등 적용 가능한 공개 정책·법적 근거를 문서화합니다.
3. **공식 절차 접수 (합법적 경로 전용)**
   - 정보통신망법 제44조의2 임시조치(블라인드), 개인정보 노출 신고, 각 플랫폼의 공식 권리침해·DMCA 접수 절차를 통해 요청합니다. 비공개 계정 침투나 불법 크롤링은 수행하지 않습니다.
4. **검색엔진 스니펫 갱신 및 재노출 점검**
   - 원문이 `HTTP 404 / 410` 삭제 처리된 후에도 검색 결과에 요약 문구가 남을 수 있으므로, 구글 오래된 콘텐츠 삭제 요청 및 네이버 검색 반영 확인을 별도로 진행합니다.

## 3. 디지털장의사 · 온라인 평판관리 의뢰 전 필수 검증 7가지

- [ ] 상호, 대표자명, 사업자등록번호, 실제 사업장 주소가 투명하게 공개되어 있는가
- [ ] 정보통신망법·플랫폼 공식 신고 등 합법적 공개 절차로만 처리하는가
- [ ] ‘무조건 100% 삭제 보장’ 같은 과장 문구 대신 사전 진단 후 가능 범위를 안내하는가
- [ ] 착수 전 계약서·비용 산정 기준·환불 정책을 서면으로 고지하는가
- [ ] 원문 URL뿐 아니라 미러·스크랩·구글/네이버 검색 스니펫까지 분리 추적하는가
- [ ] 진행 경과와 삭제 완료 결과를 근거 기록과 함께 투명하게 공유하는가
- [ ] 개인 과거글 정리와 기업·임원 평판관리(허위 리뷰·커뮤니티 대응) 체계가 구분되어 있는가
